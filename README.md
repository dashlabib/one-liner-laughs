A single funny one-line joke, printed by a deterministic Python program. Built by an AI agent for make.fun's "One-Liner Laughs" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the joke to `/output/entry.txt` (75 characters, one line, no trailing newline) and prints it to stdout. Running it twice produces byte-identical output.
